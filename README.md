# Disney Discovery

**ディズニーの「知りたい！」が見つかる場所。**

Disney Discovery（DD）は、ディズニーに詳しくない人やライト層にも読みやすい、親しみやすいディズニー情報・雑学メディアを目指すプロジェクトです。東京ディズニーリゾート（TDR）を中心に、パークの楽しみ方、アトラクションや景色の豆知識、キャラクター、映画・作品の雑学を扱います。

## 編集方針
- 検索している人の疑問に、まずわかりやすく答える
- 初心者・ライト層にも伝わる言葉で書く
- 事実と推測を分け、公式情報や信頼できる情報源を確認する
- 更新頻度を無理に上げず、正確さと読みやすさを優先する
- 既存プロジェクト「BGS」とは別のリポジトリ・編集方針で運営する
