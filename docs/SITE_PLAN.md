# Disney Discovery — サイト企画書

## 1. コンセプト
**ディズニーの「知りたい！」が見つかる場所。**

ディズニーについてふと疑問に思ったことを、初めての人にもわかりやすく解決できる、親しみやすい情報・雑学メディアを目指す。

## 2. 想定読者
- 東京ディズニーリゾートに行く予定の初心者
- 年に数回程度パークを楽しむライト層
- ディズニー映画やキャラクターに興味を持ち始めた人
- SNSや検索で見かけた疑問・豆知識を確かめたい人

専門用語やファン向けの前提知識に頼らず、必要な背景は本文で簡潔に説明する。

## 3. 扱うテーマ（初期案）
1. **パーク初心者ガイド** — チケット、公式アプリ、当日の準備、基本的な楽しみ方
2. **アトラクション・パークの豆知識** — 演出、デザイン、エリアの背景など、確認可能な事実を中心に紹介
3. **キャラクター図鑑** — キャラクターの特徴、登場作品、関係性など
4. **映画・作品の雑学** — 作品の背景、設定、キャラクターに関する疑問
5. **最新情報** — 公式発表をもとに必要な範囲で扱う。更新負荷が高いため、初期の主軸にはしない

この分類は初期案であり、検索需要や運営負荷を確認してから確定する。

## 4. BGSとの違い
- **Disney Discovery:** 初心者・ライト層向け。検索の疑問解決と読みやすさを重視する。
- **BGS:** ディズニーのバックストーリーや深掘り系を中心とする既存プロジェクト。

DDはBGSの記事を単純に言い換えて量産せず、読者・検索意図・記事構成を区別する。必要な場合も、重複内容や相互リンクは個別に検討する。BGSリポジトリはこのプロジェクトの作業対象に含めない。

## 5. ブランドの雰囲気
- **デザイン方向（初稿）:** 親しみやすい雑学メディア
- **配色の初稿:** クリーム系の明るい背景に、ブルーとイエローをアクセントとして使用。正式なブランドカラーは未確定
- 親しみやすく、明るく、落ち着いている
- 雑学は「へえ！」と思えるが、誇張や断定で煽らない
- 見出しは本文の内容を正確に表す
- 読者を置いていかない平易な日本語
- 写真が少なくても成立する、文章・図解・整理された情報を中心にした設計

## 6. 編集・運営上の優先順位
1. 情報の正確性と読者の疑問解決
2. 検索意図への適合
3. 独自の説明・構成・読みやすさ
4. 無理なく維持できる更新頻度
5. 必要な範囲でのSNS共有や再訪導線

## 7. 未決定事項
- ロゴの正式デザイン・ブランドカラーの最終決定・細部のサイトデザイン
- サイトの実装技術・ホスティング（現状はHTML/CSSの初稿のみ。採用構成は未決定）
- 初期記事と公開順
- カテゴリの最終構成
- 収益化の有無と時期

これらは独断で確定せず、ユーザーと相談して決める。

## 8. 初期ページの状況
- `index.html`: トップページ初稿。サイト紹介、テーマ別カテゴリ、記事準備中の表示、運営者プロフィールへの導線を用意。
- `profile.html`: 運営者プロフィール初稿。未確認の個人情報は創作せず、運営方針を中心に記述。
- `assets/css/style.css`: 共通スタイルとレスポンシブ対応の初稿。
- これらはデザイン・文章確認用の段階であり、ブラウザでの表示検証やサイト公開は未実施。
