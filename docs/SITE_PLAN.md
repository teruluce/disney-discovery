# Disney Discovery — サイト企画・運営方針

## 位置づけ（2026-11-04 承認指示に基づく再編）

ディズニーの実用情報、舞浜での体験、写真、個人的な記録、読み物を掲載する独立した情報サイト。閉鎖・縮小・全面リニューアルではなく、既存資産を活用しながら改善しやすい構成にする。

サイト名はDisney Discovery、公開URLは https://teruluce.github.io/disney-discovery/ を維持する。

## トップページの情報構造

1. 注目記事・おすすめ：交通、風景、写真撮影の入口。
2. 来園準備・アクセス：交通、京葉線・武蔵野線、チケット、アプリ、決済、天候、持ち物。
3. パークの発見・楽しみ方：昼夜の風景、エリア、写真、公演、歴史・豆知識。
4. Discovery Journal：本人の体験と写真の独立した記録。既存スタンプラリー記事を代表記事として案内する。
5. ディズニーの読み物：キャラクター、映画・作品、歴史、その他の豆知識。記事は残し、トップでの優先度を控えめにする。

既存の記事一覧の検索・カテゴリーは維持し、表示順と紹介文で整理する。新たな細分類ページやURLは作らない。既存のtheme-01〜05のアンカーも保持する。

## BGS Chroniclesとの役割分担

- BGS Chronicles：主力ブランド。BGS、物語、世界観、イマジニアリングを深く扱い、品質と世界観の一貫性を優先する。
- Disney Discovery：実用情報、体験、写真、読み物。背景設定の詳しい解説はBGSに案内する。
- BGSの変更・記事移植は本プロジェクトに含めない。相互リンクは必要な文脈で使い、内容を複製しない。

## 保持する資産と構成

- 本文64記事（日本語51、英語12、Journal1）、そのURL、旧URL転送3ページを維持する。
- articles/、en/、journal/のディレクトリ構成と、HTML/CSSの静的サイト構成を維持する。
- Journalは最新情報ガイドと分け、体験日と時点を示した記録として残す。本人が書いていない出来事・感情は追加しない。
- 英語は交通・Suicaと決済・マナー・写真撮影・初来園を重視する。全記事の翻訳や日英同数を目標にしない。
- 不必要な新規記事、CMS、フレームワーク変更、管理画面、実験システムは導入しない。

## 更新負担を抑える記事の役割

- 初来園：全体の準備の流れを示し、チケット・アプリ・サービスの詳細は個別記事へ案内する。
- アクセス：全体ルートを案内し、電車で迷う点は列車ガイドへ相互リンクする。
- ショー総合：個別公演・年度記事への入口と公式確認方法を担当する。
- 天候・持ち物：重なる説明を必要に応じて短くし、関連記事で補完する。
- 年度記事：終了を明記し、過去資料として維持する。検索実績を確認せず削除・統合しない。

## 品質と将来の検証

運営上はSEO、UI、記事構成、技術改善、AI品質監査を柔軟に検証する。読者向けに「実験場」を強調しない。変更ごとに仮説・変更範囲・検証・未確認事項をPRに残し、検索実績がなければ効果を断定しない。

公式情報、編集上の提案、本人の体験、考察を区別する。根拠のない事実、体験、写真は追加しない。著者・公開日・更新日は確認できるものだけを記載し、体験日やファイル日時から公開日を推測しない。

ライトテーマ、既存の余白・星のモチーフ、レスポンシブ表示、アクセシビリティ、SEO設定を維持する。余分なスクリプト・装飾・外部依存を増やさない。

既存のメタ同期・静的チェック・ブラウザ検証・Journal保持検査を用いる。本番公開・マージは運営者の承認後に行う。
