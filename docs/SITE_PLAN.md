# Disney Discovery — サイト企画書

## 1. コンセプト
**ディズニーの「知りたい！」が見つかる場所。**

初めて来園する人やライト層が、準備や当日の行動で迷わないための実用情報を中心に扱う。チケット・アプリ・回り方・サービスの選び方などの疑問に答え、キャラクターや映画の雑学も親しみやすく紹介する。

## 2. 想定読者
- 東京ディズニーリゾートに行く予定の初心者
- 年に数回程度パークを楽しむライト層
- ディズニー映画やキャラクターに興味を持ち始めた人
- SNSや検索で見かけた疑問・豆知識を確かめたい人

専門用語やファン向けの前提知識に頼らず、必要な背景は本文で簡潔に説明する。

## 3. 扱うテーマ
1. **パーク初心者ガイド** — チケット、公式アプリ、当日の準備、基本的な楽しみ方
2. **アトラクション・パークの豆知識** — 演出、デザイン、エリアの背景など、確認可能な事実を中心に紹介
3. **キャラクター図鑑** — キャラクターの特徴、登場作品、関係性など
4. **映画・作品の雑学** — 作品の背景、設定、キャラクターに関する疑問
5. **パレード・ショー** — レギュラー公演や季節のエンターテイメント、鑑賞のための判断材料

最新情報は公式発表を確認し、更新負荷も考慮して必要な範囲で扱う。

## 4. BGSとの違い
- **Disney Discovery:** 初心者・ライト層向け。準備・回り方・選び方など、実際の行動につながる疑問解決と読みやすさを重視する。
- **BGS:** ディズニーのバックストーリーや深掘り系を中心とする既存プロジェクト。

DDはBGSの記事を単純に言い換えて量産せず、読者・検索意図・記事構成を区別する。必要な場合も、重複内容や相互リンクは個別に検討する。BGSリポジトリはこのプロジェクトの作業対象に含めない。

## 5. ブランドの雰囲気
- **現在のデザイン:** 読みやすい余白と、星のモチーフを用いた明るい紙面風の構成
- **現在の配色:** 白・淡いブルー・薄いラベンダーを基調とするライトテーマ。端末側のダークモード設定にかかわらず明るい配色を使用
- 親しみやすく、明るく、落ち着いている
- 雑学は「へえ！」と思えるが、誇張や断定で煽らない
- 見出しは本文の内容を正確に表す
- 読者を置いていかない平易な日本語
- 写真が少なくても成立する、文章・図解・整理された情報を中心にした設計

## 6. 編集・運営上の優先順位
1. 情報の正確性と読者の疑問解決
2. 検索意図への適合
3. 独自の説明・構成・読みやすさ
4. 無理なく維持できる更新頻度
5. 必要な範囲でのSNS共有や再訪導線

## 7. 未決定事項
- ロゴの正式デザイン・ブランドカラーの最終決定・細部のサイトデザイン
- 今後の記事テーマと公開順
- 今後のカテゴリ構成の見直し
- 収益化の有無と時期

これらは独断で確定せず、ユーザーと相談して決める。

## 8. ページの状況
- `index.html`: トップページ。新着記事、テーマ別の導線、便利なツール、サイト紹介。
- `articles/index.html`: 記事一覧。
- `articles/*.html`: 初心者ガイド、パークの豆知識、キャラクター、映画・作品、パレード・ショーの記事。旧URLからの転送ページも含む。
- `en/`: 英語版トップ・サイト紹介・記事一覧・実用ガイド。
- `profile.html`、`contact.html`、`privacy.html`、`404.html`: 運営者・連絡先・方針・エラーページ。
- `assets/css/style.css`: 全ページ共通のスタイル（白と淡い寒色を基調にしたライトテーマ）。
- `sitemap.xml`、`robots.txt`、`favicon.svg`、`assets/img/og-default.png`: 検索・共有用のファイル。
- HTML/CSSの静的サイトとして構成し、GitHub Pagesで公開。公開先URLは https://teruluce.github.io/disney-discovery/ 。
- 新しい記事を追加するときは、対応言語の既存記事を参考にし、その言語の記事一覧と `sitemap.xml` に登録する。トップページは新着・テーマ導線を必要に応じて更新し、全記事を並べない。
